# Aurelle — The Art of Fine Dining 🥂

A modern, luxury-inspired web application built with **React**, **TypeScript**, and **Vite**, designed to bring an elevated fine-dining experience into the digital space.

## 🌐 Live Demo
🔗 **[View Live Website](https://aurelle-fine-dinning.netlify.app/)**

## ✨ Key Features
- **Luxury UI/UX Design:** Elegant typography, visual hierarchy, and smooth user flow.
- **Interactive Menu & Reservations:** Dynamic menu showcase, signature experiences, and reservation workflows.
- **Admin Dashboard:** Built-in management interface for handling restaurant content.
- **Fully Responsive:** Optimized for desktop, tablet, and mobile devices.

## 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Vite, CSS
- **Deployment:** Netlify
